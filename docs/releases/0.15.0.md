# ChatPulse 0.15.0

Production & Scale 3.0 hardens ChatPulse for multiple Cloud Run instances.

- Redis operational runtime with explicit required/optional behavior.
- Token-owned distributed scheduler leases.
- Policy-based atomic rate limits and webhook backpressure.
- Request IDs, structured redacted logs, protected Prometheus metrics, and optional scrubbed Sentry.
- Explicit PostgreSQL pools, statement timeout, slow-query events, and audited additive indexes.
- Migration-safe deployment, immutable Cloud Run release workflow, smoke checks, and rollback.
- Load smoke/staging profiles, restore verification, security gates, and non-root container checks.

Redis remains ephemeral and PostgreSQL remains the source of truth for all durable product state.
